# ABMAX ANALYSIS — SUPABASE CUSTOM SMTP (BREVO) & EMAIL TEMPLATES SETUP GUIDE

This guide provides the exact configuration required to connect your **Brevo (formerly Sendinblue)** transactional email account to your existing Supabase project (`https://fxzurpdymuhlfkdxfgel.supabase.co`) and install the branded email templates.

---

## 1. Brevo Custom SMTP Credentials Checklist

Log into [Brevo Dashboard](https://app.brevo.com/) -> Click your account name at top right -> **SMTP & API** -> **SMTP** tab.

Enter these values into **Supabase Dashboard** -> [Project Settings](https://supabase.com/dashboard/project/fxzurpdymuhlfkdxfgel/settings/auth) -> **Authentication** -> **SMTP Settings**:

| Setting Field in Supabase | Recommended Production Value | Description |
| :--- | :--- | :--- |
| **Enable Custom SMTP** | **ON / Enabled** | Toggles custom SMTP delivery |
| **Sender Email** | `support@yourdomain.com` (or your verified Brevo sender email) | Must match an active verified sender in your Brevo account |
| **Sender Name** | `AbMax Analysis` | App brand name displayed in user email inbox |
| **Host** | `smtp-relay.brevo.com` | Brevo transactional relay hostname |
| **Port** | `587` | Standard secure submission port |
| **Minimum TLS Version** | `TLSv1.2` | Enforces modern encrypted transport |
| **User** | Your Brevo account login email (e.g., `you@example.com`) | Brevo SMTP login identifier |
| **Password** | Your Brevo SMTP Key (master password) | Generate under Brevo SMTP & API > SMTP tab |

> **Security Rule:** Never commit Brevo SMTP passwords or private API keys to code or Git. Enter them directly into the Supabase Dashboard.

## 2. Supabase URL Configuration & Redirect URLs Whitelist

In Supabase Dashboard -> **Authentication** -> **URL Configuration**:

1. **Site URL**:
   - `https://abmax-analysis.pages.dev` (or your custom domain)
2. **Redirect URLs (Allow list)**:
   Add each of the following URLs to permit both web and Android mobile deep-linking:
   - `https://abmax-analysis.pages.dev/**`
   - `com.abmax.analysis://auth/callback`
   - `http://localhost:3000/**` (for local development & preview)

## 3. Branded Email Templates Installation

In Supabase Dashboard -> **Authentication** -> **Email Templates**:

### Template A: Confirm Signup (Email Verification)
1. Select **Confirm signup**.
2. Set **Subject**: `Confirm your AbMax Analysis account`
3. In **Message Body**, copy and paste the full HTML content from:
   `supabase/email-templates/confirm-signup.html`
4. Click **Save Changes**.

### Template B: Reset Password
1. Select **Reset password**.
2. Set **Subject**: `Reset your AbMax Analysis password`
3. In **Message Body**, copy and paste the full HTML content from:
   `supabase/email-templates/reset-password.html`
4. Click **Save Changes**.

---

## 4. Supported Template Variables
The included templates use standard Supabase Auth variables:
- `{{ .ConfirmationURL }}`: The secure, one-time verification or password-reset URL generated by Supabase.
- `{{ .Token }}`: The 6-digit numeric OTP verification code displayed prominently in the signup email for immediate in-app entry.
- `{{ .SiteURL }}`: The base site URL configured in your project.
